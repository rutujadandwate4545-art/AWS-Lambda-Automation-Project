# AWS Lambda Automation Project

## Project Overview
This project automates file uploads and downloads using Python and AWS services.

## Features
- Upload files to Amazon S3.
- Download files from Amazon S3.
- Generate CSV reports.
- Automate file-processing tasks using Python.
- Track upload and download results.

## Technologies Used
- Python
- Amazon Web Services (AWS)
- Amazon S3
- Boto3
- Git and GitHub

## Project Files
- `main.py` — Main Python application.
- `automatic_upload_report_rutuja (3).csv` — Automatic upload report.
- `s3_upload_report_rutuja.csv` — S3 upload report.
- `README.md` — Project documentation.

## Prerequisites
- Python 3
- An AWS account
- AWS credentials configured securely with the required permissions.

## Installation
Install Boto3 if it is not already installed:

```bash
pip install boto3
```

## Running the Project
Run:

```bash
python main.py
```

## Security
Never commit AWS access keys, secret keys, passwords, or other sensitive information to GitHub.
